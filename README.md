# Nederlandse clubs in Europa – agenda-abonnement

Alle wedstrijden van Nederlandse clubs in de Champions League, Europa League en Conference League,
automatisch elke 6 uur bijgewerkt (nieuwe loting, gewijzigde aftraptijden, uitslagen).

**Abonneren:** `webcal://jasper87000.github.io/dutch-european-ical/nl-europa.ics`

- Bronnen: UEFA-wedstrijddata, met ESPN als reserve.
- Wedstrijden worden nooit verwijderd; als een bron faalt blijft de laatste goede kalender staan.
- Status van de laatste run: `data/status.json`.
- Handmatig bijwerken: tabblad **Actions** → *Kalender bijwerken* → **Run workflow**.
